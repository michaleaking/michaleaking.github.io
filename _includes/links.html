{%- comment -%} Renders a row of labelled links. Used by the Team, Tools and Research pages. Usage: {% include links.html items=person.links %} {% include links.html items=tool.links primary=tool.repo primary_label="View on GitHub" %} items list of { label, url } pairs from a _data file. An entry with no label falls back to its domain name, so a bare url still shows something sensible; blank urls are skipped. primary optional single url rendered first, for the shorthand fields that predate `links` (a tool's `repo`, a person's `link`). primary_label text for that first link. Defaults to "Link". {%- endcomment -%} {%- assign items = include.items | default: empty -%} {%- assign has_primary = false -%} {%- if include.primary and include.primary != '' -%}{%- assign has_primary = true -%}{%- endif -%} {%- if has_primary or items.size > 0 -%}
